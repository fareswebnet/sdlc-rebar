# $preset-system-merge

- Use for acquisitions, tenant or product consolidation, or adding a second legacy source to a target.
- Run `harnesses/system-merge.yaml` and `$sdlc-system-merge-convergence`.
- Keep one registry with a source column, a rule matrix per source, and per-source visas.
- Require named owners for data, identifiers, contracts, and contradictory rules.
- Run cumulative regression of all earlier sources before every close.
