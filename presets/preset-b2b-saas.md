# preset-b2b-saas

- Use for multi-tenant SaaS, team accounts, admin consoles, subscriptions, enterprise onboarding, or customer success loops.
- Prioritize tenant isolation, roles/permissions, billing/entitlement, admin workflows, support feedback, analytics, and production readiness.
- Default architecture: modular monolith, clear bounded contexts, PostgreSQL, background jobs, OpenAPI, feature flags, and strong observability.
